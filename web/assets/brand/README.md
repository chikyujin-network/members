| ファイル | サイズ | 用途 |
| --- | --- | --- |
| logo-komagane.png | 816×762、背景透過 | 画面のヘッダー、会員証 |
| logo-komagane-on-blue.png | 1024×1024、水色背景 | SNSや資料用の正方形ロゴ |
| icon-512.png / icon-192.png | 水色背景 | Webアプリのアイコン（ホーム画面に追加したとき） |

## 注意

- 印刷物を撮影したものなので、色は実物より少しくすんでいます。画面に使うときは、実物と見比べて調整してください
- 元のデザインデータ（Illustratorファイルや高解像度の画像）が運営にあれば、そちらに差し替えるのが望ましいです
- ロゴの使用について、パンフレットの制作者や運営に念のため確認してください
