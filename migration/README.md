# 旧Excelからの移行

旧Excel（2026年度名簿）を、新しいスプレッドシートの「会員」「年度請求」シートに貼り付けられる CSV に変換します。

**入力の Excel と出力の CSV には個人情報が含まれます。リポジトリの外のフォルダで実行し、出力をリポジトリに入れないでください。**

## 使い方

```bash
pip3 install openpyxl
python3 migration/convert.py --input "/path/to/2026地球人名簿 .xlsx" --output-dir "/path/to/移行出力"
```

## 出力

| ファイル | 内容 |
| --- | --- |
| `会員.csv` | 会員シートに貼り付ける（列の順番は `gas/src/schema.ts` と同じ） |
| `年度請求.csv` | 年度請求シートに貼り付ける |
| `対応表_旧名簿の行と会員番号.csv` | 旧名簿の何行目が、どの会員番号になったか |
| `要確認_名寄せ.csv` | 会費・保険の名簿の名前が、名簿と一致しなかったもの（候補付き） |
| `要確認_重複.csv` | 同じ名前の行を1人にまとめたもの |
| `要確認_氏名欄の振り分け.csv` | 氏名欄のカッコ書き・改行メモと、よみ・ニックネーム・別名の振り分け案 |
| `要確認_会費欄の記号.csv` | 会費欄の「△」「▽」など、意味が決まっていない記号 |
| `移行レポート.md` | 件数のまとめと注意点 |

## 変換のルール

- 会員番号は、旧名簿の行の順（表示されていた行が先、非表示の行が後）に `001-00100` から振る
- 年度列（R8〜H25）の「〇」は、その年度の会費「支払済」。2025年度以前は金額と受領日が不明なので空欄
- 2026年度の会費は500円、受領日は旧名簿の「R8領収日」。会費納入の名簿のメモ（「〇〇さんへ」など）は備考に入れる
- 2027年度の名簿にある人は、2027年度の会費を前払いとして記録する
- 保険料は総額500円・本人負担330円・補填170円。補填元は旧名簿の居住地からの推定（住民票の確認が必要）
- 名前の下線部分はニックネームに、カタカナの名前はそのまま「よみ」にする
- 市外局番のない自宅電話には 0265 を付ける。読めない番号は備考に残す
- 2025・2026年度に会費の記録がある人を「活動中」、それ以外を「休眠」にする
